### 🚀 Featured Projects

#### 🏔️ Alpine
A minimalist Minecraft modding hub with a clean, dark-mode interface accented with pastel green. Features Modrinth API integration and Discord-style community features.
- **Status:** Active Development
- **Tech:** Java, JavaScript, CSS3, Fabric

#### 🎆 Fireworks Engine
A performance-first game engine built from scratch specifically for low-end hardware. Emphasizes efficient rendering, minimal memory footprint, and maximum frame rates.
- **Status:** In Development
- **Tech:** Java, GLSL, Custom Language (Helium)
- **Focus:** Optimization, minimalist architecture, custom rendering pipeline

#### 💡 Real Lighting (RL)
A high-fidelity Minecraft shader project that brings realistic, physically-based lighting to block-based worlds without sacrificing performance.
- **Status:** Active Development
- **Tech:** GLSL, Minecraft Shader Modding
